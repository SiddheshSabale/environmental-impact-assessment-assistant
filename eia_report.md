## 5. Preliminary Mitigation Recommendations  

| Impact | Preliminary mitigation measures (not legally binding) |
|--------|------------------------------------------------------|
| Air emissions | • Install high‑efficiency particulate filters (e.g., ESP/Baghouse).<br>• Use low‑NOₓ combustion controls (e.g., staged combustion, SCR).<br>• Continuous emission monitoring systems (CEMS) for key pollutants.<br>• Optimize waste feedstock to reduce chlorine‑containing materials. |
| Stack effluent composition | • Conduct pilot‑scale testing to characterize flue‑gas composition.<br>• Implement wet/dry scrubbers for acid gases.<br>• Regular maintenance of emission control equipment. |
| Water demand | • Adopt closed‑loop boiler water treatment to minimize fresh‑water intake.<br>• Use rainwater harvesting where feasible.<br>• Conduct water‑balance study. |
| Wastewater / process effluent | • Design effluent treatment plant (ETP) to meet discharge standards.<br>• Re‑use treated water for ash cooling or dust suppression.<br>• Leak‑detection and secondary containment for storage tanks. |
| Solid residues (ash) | • Characterize ash for hazardous constituents.<br>• Develop ash utilization plan (e.g., construction material) if non‑hazardous.<br>• Secure, lined ash storage with leachate collection. |
| Soil contamination | • Install impermeable liners under ash storage and wastewater ponds.<br>• Implement regular soil monitoring around storage areas. |
| Noise | • Enclose noisy equipment, install acoustic baffles.<br>• Schedule high‑noise activities during daytime.<br>• Provide hearing protection for workers. |
| Traffic & transport | • Optimize waste collection routes to reduce vehicle kilometres.<br>• Use low‑emission trucks where possible.<br>• Design dedicated entry/exit points to minimize community disruption. |
| Land use & visual impact | • Landscape the site perimeter with native vegetation.<br>• Use architectural design that blends with surrounding built environment.<br>• Minimize footprint through compact plant layout. |
| Biodiversity | • Conduct a rapid biodiversity assessment before land clearing.<br>• Preserve any identified trees or habitats where feasible.<br>• Implement a habitat restoration plan if impacts are unavoidable. |
| Occupational health & safety | • Develop a site‑specific OHS plan (heat stress, respiratory protection, confined spaces).<br>• Provide regular training and medical surveillance for staff. |
| Public health & community exposure | • Install ambient air‑quality monitoring stations around the plant.<br>• Establish a grievance redress mechanism for nearby residents.<br>• Communicate emission data transparently. |
| Construction waste | • Segregate construction debris for recycling.<br>• Manage hazardous construction waste (e.g., paints, solvents) per hazardous waste rules. |

These measures are **preliminary** and should be refined after detailed baseline studies and regulatory consultations.
